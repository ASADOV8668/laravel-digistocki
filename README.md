# Digistocki

پایه‌ی فاز اول سامانه‌ی آگهی‌گذاری موبایل برای بازار ایران با Laravel 11، Blade، Tailwind CSS، Alpine.js و Heroicons.

## اجرای محلی

پروژه در مسیر `C:\xampp\htdocs\app` ساخته شده و برای اجرای Apache در زیرپوشه‌ی `app` تنظیم شده است.

```bash
composer install
npm install
npm run build
php artisan key:generate
php artisan storage:link
php artisan test
```

مقادیر اصلی محیط محلی در `.env`:

```env
APP_URL=http://localhost/app
ASSET_URL=http://localhost/app
DB_DATABASE=app
DB_USERNAME=root
DB_PASSWORD=
```

فاز اول شامل Breeze Blade با Alpine، پوسته‌ی موبایل‌محور RTL، فونت Vazirmatn، پالت برند، لوگوی SVG، PWA manifest/service worker، Top Bar، Drawer سمت چپ و Bottom Navigation است.

## فاز ۲: هسته‌ی دامنه و جریان آگهی

در فاز دوم این بخش‌ها اضافه شده‌اند:

- migrationهای کاربران، برندها، مدل‌ها، ویژگی‌های EAV، آگهی‌ها، تصاویر، علاقه‌مندی‌ها و گزارش‌ها؛

- قوانین سقف ۱۰ آگهی فعال، تکراری نبودن آگهی در ۲۴ ساعت و انقضای ۳۰ روزه؛

## فاز ۶: صفحه Single، تماس امن و آگهی‌های مرتبط

صفحه‌ی جزئیات هر آگهی بازطراحی و کامل شد:

- OTP پنج دقیقه اعتبار، حداکثر پنج تلاش و ذخیره‌ی hash‌شده دارد؛ حالت تست فقط در `storage/logs/laravel.log` ثبت می‌کند و حالت واقعی از وب‌سرویس Pattern آی‌پی‌پنل استفاده می‌کند؛
- آگهی‌های مرتبط بر اساس همان مدل، برند و ویژگی‌های مشترک در پایین صفحه نمایش داده می‌شوند.

## فاز ۱۰: پردازش و بهینه‌سازی تصاویر

مدیریت تصاویر آگهی با سرویس مستقل تکمیل شد:

- نصب `intervention/image`؛
- تولید نسخه‌ی اصلی WebP با حداکثر ابعاد ۱۲۰۰×۱۲۰۰ و thumbnail با ابعاد ۴۰۰×۴۰۰ درایور GD؛
- ذخیره‌ی مسیر thumbnail در ستون جدید `listing_images.thumbnail_path`؛
- استفاده از thumbnail در کارت‌های آگهی و داشبورد برای کاهش حجم بارگذاری؛
- حذف هم‌زمان نسخه‌ی اصلی و thumbnail هنگام حذف تصویر یا آگهی؛
- fallback امن به فایل اصلی در محیط‌هایی که GD فعال نیست؛
- حفظ محدودیت ۸ تصویر و سقف قابل تنظیم برای هر تصویر (پیش‌فرض ۵ مگابایت).

برای فعال شدن پردازش WebP در XAMPP، extension مربوط به GD را در `C:/xampp/php/php.ini` فعال و Apache/PHP را restart کنید.

## انتقال به سرور FTP

در زمان انتشار، این موارد را انجام دهید:

1. مقدارهای `APP_URL` و `ASSET_URL` را در `.env` به `https://digistocki.com` تغییر دهید.
2. دستورات `php artisan config:cache`، `php artisan route:cache` و `php artisan view:cache` را اجرا کنید.
3. روی سرور `php artisan storage:link` را اجرا کنید.
4. Document Root را روی `public/` قرار دهید؛ اگر امکان‌پذیر نیست، `.htaccess` را برای هدایت به `public/` تنظیم کنید.
5. پوشه‌ی `storage` و لینک/پوشه‌ی `public/storage` را منتقل یا در مقصد ایجاد کنید.
6. اتصال دیتابیس مقصد را تنظیم و `php artisan migrate --force` و `php artisan db:seed` را اجرا کنید.
7. assetهای build شده در `public/build` را روی سرور آپلود کنید.
8. مجوز نوشتن پوشه‌های `storage` و `bootstrap/cache` را تنظیم کنید.

هیچ دامنه‌ی واقعی در Blade، JavaScript یا CSS هاردکد نشده است؛ URLها با `url()`، `asset()` و `route()` ساخته می‌شوند.

فاز ۱۹۸ برای قالب عمومی و پنل مدیریت landmark محتوای اصلی با شناسه و برچسب مشخص اضافه کرده و منوی اصلی سایت را با برچسب ناوبری قابل تشخیص برای صفحه‌خوان‌ها تکمیل کرده است.
